# Governance

@kevindm-design maintains Tersalang and has final say on changes.

The language changes through Tersalang Enhancement Proposals (TEPs) in `teps/`. The interpreter follows the specs in `spec/`; where they leave a point open, `docs/spec-notes.md` records what the interpreter does.

Pull requests merge after CI passes and a maintainer approves. Changes to `spec/` need the maintainer's review (`CODEOWNERS`).
